# Repository Docs

This directory contains interfaces, prompt references, and formal-method notes spanning more than one procedure.  Procedure-specific rules and proof references remain under `adc/docs/`, `arb/docs/`, and `arbd/docs/`, while simple and quick keep their operating references beside their code.  The repository-level [unified command reference](../adjudication-cli.md) defines complete one-case execution for all five procedures.

## Documents

| Document | Use |
| --- | --- |
| [Unified Adjudication Command](../adjudication-cli.md) | One-case request, settings, participant profiles, process behavior, and result interface for all five procedures. |
| [Proof Work Status](proof-notes.md) | Current proof surface, certificate status, remaining proof direction, and proof limits. |
| [Core Process Interface](service-interface.md) | Core commands, private case APIs, durable records, and interface tests used by services. |
| [Prompt Authoring](prompt-authoring.md) | Core, MCP, and launcher prompt precedence, literal tokens, command-line options, and evaluation practice. |
| [Council and Jury Model Endpoints](model-endpoints.md) | Pool records, endpoint-balanced selection, credentials, and direct or Pi model execution. |
| [Pi Container Image](../containers/pi/README.md) | Image build and participant environment. |
| [AAR Local Runner](../runtime/localrun/arb/README.md) | Participant profiles, process supervision, and retained files. |
| [marXiv Reports](../reports/marxiv/README.md) | Papers on procedures, evaluations, and model-pool generation. |

The [ADC](../adc/docs/README.md), [ARB](../arb/docs/README.md), and [AARD](../arbd/docs/README.md) indexes link their procedure-specific documentation.
