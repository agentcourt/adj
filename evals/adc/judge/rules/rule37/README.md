# Rule 37

The Rule 37 suite evaluates `decide_rule37_motion`.  Its sixteen fixtures cover discovery failures, justified objections, proportionality, harmlessness, prior-order violations, and sanction constraints.  The scorer checks the grant decision, sanction type and amount, reason tags, invalid payloads, and action execution.
