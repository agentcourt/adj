# Rule 60

The Rule 60 suite evaluates `resolve_rule60_motion`.  Its sixteen fixtures cover mistake, new evidence, fraud, void judgments, changed circumstances, timeliness, unsupported requests, and repeated trial arguments.  The scorer checks grant, required and prohibited content, reason tags, invalid payloads, and Lean acceptance.
